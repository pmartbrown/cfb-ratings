# College Football Ratings

Weekly power ratings for every FBS team, built from on-field results only (no polls or betting lines as inputs).
Site: https://pmartbrown.github.io/cfb-ratings/

This repository contains only the static website (`docs/`) and the weekly model output it displays
(ranks, ratings, records, movement) in `docs/data/`. Methodology: see the About page.

Data provided by CollegeFootballData.com. Schedules and play-by-play from the sportsdataverse project.
Model output, not betting advice.
